# Jafaali & Ritah Wedding Intro

Cinematic 23-second wedding title sequence built with Remotion.

## Sequence
- Two hearts…
- One beautiful journey…
- THE MARRIAGE CELEBRATIONS OF
- JAFAALI SUUNA NKATA & RITAH BIRUNGI
- 14TH AUGUST 2026
- KIWATULE — Mr. & Mrs. Nkata’s Home

## Run on Windows

Install Node.js, then open PowerShell in this repository:

```powershell
npm install
npm start
```

To render the final MP4:

```powershell
npm run render
```

Output: `out\\jafaali-ritah-wedding-intro.mp4`

The composition is 1920x1080 at 30fps. No third-party video watermark is added by this project.
