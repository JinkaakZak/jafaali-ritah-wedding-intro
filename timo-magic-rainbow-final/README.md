# Timo and the Magic Rainbow

A complete 2-minute, 1080p, 30fps Remotion children's animation master.

## Final specification
- Duration: 2:00
- Resolution: 1920x1080
- Frame rate: 30fps
- 8 scenes x 15 seconds
- Original characters: Timo, Lulu and Bobo
- Story: friendship, kindness and teamwork
- No copyrighted characters or third-party footage
- Procedural vector-style environments and characters, so the project has no missing image assets.

## Run locally

```powershell
npm install
npm run start
```

Render the final MP4:

```powershell
npm run render
```

Output:

`out/Timo-Magic-Rainbow-1080p.mp4`

The project is deliberately self-contained. You can later replace individual procedural scenes with AI-generated footage while keeping the same 2-minute timing and final 1080p master.
